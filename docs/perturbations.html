说明实际执行什么、参数是什么、在哪个阶段插入，以及如何尝试恢复。接口支持、产生有效错误、得到合格纠错数据是三个不同层次。

所有环境共用的调度参数

at.step / at.fraction / at.event 选择成功源轨迹中的插入位置；steps 控制持续长度，repeat / gap 控制次数与间隔，strength / parameters 控制幅度与方向。全部注入和恢复动作都计入 max_steps。

原生成功源 → 同前缀执行扰动 → 原动作对照失败／闭环恢复成功。hold、碰撞阻挡等情况可能未造成有效错误，应如实保留。不同环境的物理步、控制步、网格动作不可直接比较。
