厨房里的移动、操作与纠错。

原生 RoboCasa PickPlaceCounterToSink，PandaOmron 从初始位置移动到台面，抓起苹果、搬运到水槽并放下。左侧全景显示底盘移动，右侧原生机器人相机显示抓取细节。

限定 layout/style=1、apple、seed=1100。最终三个扰动配置均得到合格纠错：3/3 源成功、0/3 错误对照成功、3/3 恢复成功；9/9 独立动作回放通过，状态误差 0。这是同一个初始场景的三类干预，不是所有厨房、对象或种子的成功率。视频每 3 个控制动作采一帧，20 FPS 播放，不代表物理时间。

可复现命令

先配置独立 RoboCasa 环境与 Objaverse／Lightwheel 资产。所有注入、恢复动作计入 700 步预算；成功仍由原生“物体在水槽内且夹爪远离”判定。

python -m robot_stack.suite --backend robocasa \
  --tasks PickPlaceCounterToSink --episodes 1 --seed-start 1100 --max-steps 700 \
  --schedules examples/perturbations/robocasa-mobile-navigation.json \
              examples/perturbations/robocasa-mobile-arm.json \
              examples/perturbations/robocasa-mobile-gripper.json \
  --output outputs/kitchen-mobile
